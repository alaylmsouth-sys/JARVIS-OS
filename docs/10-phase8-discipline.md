# 8단계 · 매매 규율 시스템 (v0.8.0)

## 배경: JIOS 설계 검토 결과

사용자가 ChatGPT와 설계한 "JIOS"(AI 단타 트레이더 + 경제 OS Foundation)를 검토했다.

**채택하지 않은 것과 이유:**
- "상승 확률 78%, AI 점수 92점" — 백테스트 인프라 없는 LLM 확률은
  통계가 아니라 문장 생성(가짜 숫자)이므로 만들지 않는다.
- 자동매매 — 핵심 원칙(사람이 결정) 위반.
- Foundation/마켓플레이스/마이크로서비스 50~100개 — 1인 프로젝트 규모 아님.

**채택한 것 (검증된 지혜):**
- 7항목 점수 체크리스트 → 단, 점수는 AI가 아니라 **사용자가 정한 규칙의 합산**
- "매도 규칙을 미리 정해 감정에 흔들리지 않는다" → 계획(손절/목표/근거) 없는
  매매 기록을 시스템이 거부
- 복기 → 지어낸 확률 대신 **본인 실기록 통계**: 승률, 누적손익,
  계획 준수율, 준수시 vs 위반시 평균 수익 비교

## 구성

- memory/trade_rules.json — 체크리스트 (항목/배점/기준점 80, 전부 사용자 수정 가능)
- memory/trade_journal.json — 매매일지
- invest/discipline.py — 점수 합산 / 기록(계획 필수) / 청산 / 복기 / 통계
- 대시보드 🧭 섹션 — 체크리스트(실시간 합산), 일지, 통계 카드

## 정직성 장치

- 점수 옆에 항상: "매수 신호가 아니라 당신의 규칙"
- 표본 10건 미만이면 "⚠표본부족" 표시 (low_sample)
- 통계는 청산+복기된 실기록에서만 계산

## 테스트 (5/5 + 서버 통합)

- [x] 점수 합산 / 계획 없는 매매 3종 거부(손절0, 목표0, 근거 공백) → HTTP 400
- [x] 손익 계산(+1000원/+10%) / 복기 후 준수·위반 평균 분리(+10% vs -5%)
- [x] 표본 부족 플래그 / 중복 청산 거부
