# JARVIS OS — 비전과 원칙

## 한 줄 목표

"AI 직원들이 일하고, 나는 CEO처럼 최종 승인만 하는 시스템."

## 핵심 원칙 (변경하지 않는 규칙)

1. **CEO 최종 승인**: 모든 영상은 업로드 전에 반드시 사람이 최종 검토하고 승인한다.
   JARVIS는 절대 혼자 업로드하지 않는다.
2. **중요 작업의 승인**: 유튜브 업로드, 투자 주문, 세금 신고 등은 항상 사람의 최종 승인을 거친다.
3. **자동화의 범위**: 준비와 추천은 최대한 자동화하되, 결정은 사람이 내린다.
4. **상태의 영속성**: 모든 상태(진행률, 승인 큐, 점수, 기록)는 `memory/` 폴더의
   파일에 저장한다. AI와의 대화 세션에 의존하지 않는다.
5. **개발 방식**: 매 기능마다 "설계 → 구현 → 테스트 → 완료"를 거친다.

## 기능 센터 (v1.0 범위)

- 🎬 콘텐츠 센터: 쇼츠/롱폼 제작, 썸네일, 자막, 예약 업로드, 승인 후 업로드
- 📈 투자센터: 보유 종목, AI 분석, 뉴스 분석, 일정, 손익
- 💰 재무센터: 수익/비용, AI 사용료, 종합소득세 예상, 신고 일정, 자산
- 🤖 AI 관리센터: AI 상태, 무료 AI 추천, 정책 변경 감시, 교체 제안, 성능 비교
- 🔐 시스템센터: 백업, 복구, 보안, 로그, 업데이트
- ⭐ AI Project Manager: 진행률, 다음 작업, 오늘의 우선순위
