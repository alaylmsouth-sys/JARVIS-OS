# 12·13단계 · v1.0 큰 틀 완성 (AI 관리센터 + 시스템센터 + 시청시간)

## 전략 전환

단계별 완성 → **큰 틀 먼저 완성, 실사용하며 수정**. 이 문서로 5개 센터의
뼈대가 모두 갖춰졌다 (v1.0.0-rc: 코드는 완성, 실환경 검증이 남은 상태).

## 추가된 것

### 🤖 AI 관리센터 (agents/manager.py)
- 역할별 배정 AI, 키 설정 여부(❌면 실호출 불가), 호출/토큰/비용, 마지막 호출
- 경고: 키 미설정 / 가격 미입력(비용 미산정) / fallback 없음
- API 호출 없음 — 파일 읽기만 (ai_usage + routing_table)

### 🛡 시스템센터 (security/health.py)
- [점검 실행] 버튼 → Python/FFmpeg, 키·유튜브 인증(토큰 권한까지),
  memory 무결성(전 JSON 파싱), 백업 최신 여부, **데이터 저장소 오염 검사**
  (JARVIS-DATA에 코드 폴더가 섞이면 경고 — 실제 발견된 문제), 산출물 용량
- 점검은 읽기만 — 아무것도 고치거나 지우지 않는다

### 🎬 성과 분석 v1.1 (video/analytics.py)
- Analytics API로 시청시간·평균 시청 추가 (스코프 yt-analytics.readonly 추가)
- **CTR/노출수는 공개 API 미제공(Studio 전용)** — 표시하지 않는다 (정직성)
- 시청시간 조회가 실패해도 기본 통계 스냅샷은 저장된다

## 남은 실환경 검증 (= "안 되는 부분 수정" 목록)

| # | 항목 | 필요한 것 |
|---|---|---|
| 1 | Gemini 실호출 (대본 생성) | GEMINI_API_KEY 설정 |
