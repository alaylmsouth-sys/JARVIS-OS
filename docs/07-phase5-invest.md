# 5단계 · 투자센터 (v0.5.0)

## 원칙 (가장 중요)

- **JARVIS는 매매 주문을 실행하지 않는다.**
- **매수/매도 추천과 가격 예측을 하지 않는다** — AI 브리핑의 시스템 프롬프트에
  금지 규칙으로 명시했고, 화면에 면책 문구가 항상 표시된다.
- 투자 판단과 책임은 사용자에게 있다. JARVIS는 정보 정리 비서다.

## 기능 (구현 완료)

- 보유 종목 관리: 추가/삭제, 통화별(KRW/USD) 원금·평가손익 집계
- 시세: 야후 파이낸스 자동 조회(키 불필요, ⚠ 실호출 미검증) + 수동 입력 폴백
- 손익 계산: 평가손익 = (현재가 − 평단) × 수량. **시세 미입력 시 "—" 표시**
  (가짜 숫자를 만들지 않음, 테스트로 검증)
- 일정 관리: 실적 발표/배당락 등 D-day
- AI 브리핑: 보유 현황 + (선택) 붙여넣은 뉴스 → 중립 브리핑.
  라우트(invest_brief)는 script 라우트의 provider/model을 복사해 자동 등록됨
  → 사용자의 gemini 설정을 그대로 따른다.
