# JARVIS Workflow v1.0 (영상 파이프라인)

```
아이디어 입력
      ↓
AI 기획
      ↓
대본 생성 (Writer AI)
      ↓
장면 설계
      ↓
영상 생성 (Video AI)
      ↓
음성 생성 (Voice AI)
      ↓
자동 편집 (Editor AI)
      ↓
썸네일 생성
      ↓
AI 품질 검사 (Quality Inspector)
      ↓
📋 CEO 검토 ★ 사람의 승인 필수 ★
      ↓
 ┌────┴────┐
 수정      승인
 │          │
 ▼          ▼
부분 재생성  유튜브 업로드
             ↓
        성과 분석 (24h: 조회수, CTR, 시청시간, 댓글)
             ↓
        Memory 2.0 저장 (성공 요인 기록)
             ↓
        다음 영상 개선
```

## Quality Inspector 체크 항목

맞춤법 / 사실관계 오류 가능성 / 영상 길이 / 음성 자연스러움 /
자막 오류 / 썸네일 품질 / 제목 클릭 유도력 / 저작권 위험 요소 /
AI 생성 오류(깨진 프레임 등)

→ 품질 점수 리포트를 만들어 승인 화면에 표시.
점수는 예측치이며 실제 성과를 보장하지 않는다.

## 부분 재생성 원칙

전체를 다시 만들지 않고 필요한 부분만 재생성한다.
예: "2번째 장면만 다시", "목소리만 차분하게", "썸네일만 다시".

## 승인 화면 구성 (Preview Center)

▶ 영상 재생 · 🖼 썸네일 · 📝 제목 · 📄 설명 · 🏷 태그 · 📊 품질 점수 · ⚠ 수정 권장

버튼: [🔄 다시 만들기] [✏ 일부 수정] [✅ 업로드 승인]

## 사용 예정 AI 후보 (2단계 AI Router에서 확정)

- 대본: ChatGPT / Claude / Gemini
- 영상: Kling / Veo / Runway / Pika / Hailuo
- 음성: ElevenLabs / Minimax
- 편집: FFmpeg 기반 자동 편집 (+ CapCut/Canva 보조)

예상 월 비용: 최소 약 5만원, 적극 사용 시 10~15만원 수준
(2026년 기준 변동 가능 — AI 관리센터가 가격/정책 변경을 감시)
