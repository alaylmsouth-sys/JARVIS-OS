# JARVIS OS 실행 가이드

이 문서는 **처음 JARVIS OS를 실행하는 사용자**를 위한 안내입니다. 대시보드를 확인하는 데 AI API 키, 유튜브 계정, 투자 계정은 필요하지 않습니다. 그런 연결은 필요한 기능을 사용하기 직전에만 설정하세요.

## 시작 전에 확인할 것

| 필요한 것 | 이유 | 확인 방법 |
| --- | --- | --- |
| Python 3.10 이상 | 대시보드를 실행하는 데 필요합니다. | 터미널에서 `python3 --version` 또는 Windows 명령 프롬프트에서 `py --version`을 실행합니다. |
| 인터넷 연결 | 첫 실행 시 필요한 라이브러리를 내려받습니다. | 브라우저에서 일반 웹페이지가 열리는지 확인합니다. |
| 프로젝트 폴더 | `run` 실행 파일이 있는 폴더입니다. | `README.md`, `run.sh`, `run.bat`가 함께 보이면 맞습니다. |

## 실행하기

### Windows

프로젝트 폴더에서 `run.bat`를 더블클릭하세요. 검은 창에 `JARVIS OS를 시작합니다`라는 문구와 주소가 나타나면 브라우저에서 `http://127.0.0.1:8000`을 엽니다. 검은 창은 서버입니다. 대시보드를 쓰는 동안 닫지 마세요.

### macOS 또는 Linux

터미널을 열고 프로젝트 폴더로 이동한 다음 아래 명령을 한 줄씩 실행하세요.

```bash
chmod +x run.sh
./run.sh
```

`JARVIS OS를 시작합니다`라는 문구가 보이면 브라우저에서 `http://127.0.0.1:8000`을 엽니다. 서버를 끄려면 터미널에서 `Ctrl+C`를 누르세요.

> 첫 실행은 가상환경과 라이브러리를 준비하므로 평소보다 오래 걸릴 수 있습니다. 이 과정이 끝난 뒤에는 같은 명령으로 바로 시작할 수 있습니다.

## 대시보드 첫 사용

첫 화면은 **오늘의 시작**입니다. 아래 중 필요한 한 가지를 선택해 보세요.

| 목적 | 열 메뉴 | 처음 할 수 있는 일 |
| --- | --- | --- |
| 진행 상황 확인 | `오늘의 시작` | 남은 작업을 보고 완료한 항목을 표시합니다. |
| 영상 검토 | `영상·승인 관리` | 영상 품질을 확인하고 승인·반려·재생성을 선택합니다. |
| 설정 확인 | `AI·시스템 상태` | AI 키, 데이터, 백업의 준비 상태를 확인합니다. |
| 기록 확인 | `업무·자산 관리` | 수익·비용·자산 기록을 확인합니다. |

연결되지 않은 AI 항목은 **대기 상태**로 보입니다. 이는 정상이며, API 키를 입력하기 전에는 외부 AI가 호출되지 않습니다. 영상 업로드와 투자 주문도 사용자의 별도 승인 없이는 실행되지 않습니다.

## 안전하게 기능을 확인하는 방법

실제 외부 서비스를 쓰지 않고 영상 파이프라인 구조를 확인하려면 아래 명령을 사용하세요. 이 명령은 placeholder 영상과 무음 트랙만 만들며, 외부 AI·TTS·영상 생성 서비스를 호출하지 않습니다.

```bash
python -m video.pipeline "테스트 주제" --dry-run
```

프로젝트의 자동 검증은 다음 명령으로 실행합니다.

```bash
python -m pytest -q
```

## 문제가 생겼을 때

| 증상 | 원인일 수 있는 것 | 해결 방법 |
| --- | --- | --- |
| `python3` 또는 `py`를 찾을 수 없다고 나옵니다. | Python이 설치되지 않았거나 PATH에 등록되지 않았습니다. | Python 3.10 이상을 설치한 뒤 새 터미널을 열어 다시 실행하세요. Windows 설치 시 `Add Python to PATH`를 선택하세요. |
| `Permission denied`가 나옵니다. | `run.sh` 실행 권한이 없습니다. | `chmod +x run.sh`를 실행하고 다시 시도하세요. |
| 브라우저에서 페이지를 열 수 없습니다. | 서버가 아직 준비 중이거나 실행 창이 닫혔습니다. | 실행 창에서 주소와 오류 메시지를 확인하고, 창을 닫지 않은 상태에서 `http://127.0.0.1:8000`을 다시 여세요. |
| `Address already in use`가 나옵니다. | 이미 같은 주소에서 JARVIS OS가 실행 중입니다. | 기존 실행 창에서 `Ctrl+C`를 누른 뒤 다시 실행하세요. |

추가 설정이나 복구가 필요하면 프로젝트 루트의 `docs/` 폴더에 있는 설계 문서를 참고하세요.
