# 4단계 · Finance Center (v0.4.0)

## 설계

```
수익/비용 장부 (memory/finance.json)
        +
AI 사용료 자동 연동 (memory/ai_usage.json ← 2단계 Router가 이미 기록 중)
        ↓
연간/월별 요약 → 순이익
        ↓
종합소득세 추정 (memory/tax_config.json 세율표)
        +
신고 일정 D-day
```

## 세금 추정 방식 (2026-07 국세청 기준으로 검증)

- 8단계 누진세율 (6%~45%), 산출세액 = 과세표준 × 세율 − 누진공제
- 과세표준 = 수익 − 총비용(장부+AI사용료) − 소득공제(기본 150만원, 설정 가능)
- 지방소득세 = 국세의 10%
- **검증**: 국세청 공식 예시(과세표준 3,000만원 → 3,240,000원)와 정확히 일치 (테스트 포함)
- **한계 (정직한 표기)**: 세액공제·감면·기납부세액(3.3% 원천징수)·건보료 미반영.
  참고용 추정치이며 실제 신고는 홈택스/세무사 확인 필수. 화면에 항상 표시됨.
- 세율표는 tax_config.json에 있어 법 개정 시 사용자가 직접 수정 가능.

## 신고 일정 (tax_config.json에서 관리)

- 종합소득세: 매년 5/31 (전년 귀속)
- 부가세 확정신고: 7/25(1기), 1/25(2기)
- 📌 2026-04부터 유튜버 등 미디어 콘텐츠 창작업은 **현금매출명세서 의무 제출** 업종 추가
- 무신고 가산세 20%, 납부지연 일 0.022%

## 사용법

```bash
python -m finance.cli add income 150000 유튜브 "애드센스"
python -m finance.cli add expense 12000 AI사용료 "fal.ai 충전"
python -m finance.cli summary
```

또는 대시보드 💰 재무센터 섹션에서 입력/삭제. AI 사용료는 자동 집계.
