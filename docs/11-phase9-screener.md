# 9단계 · 자동 분석 스크리너 (v0.9.0)

## "추천"과 "자동 분석"의 구분 (프로젝트 방침)

- ❌ 추천/확률/목표가 생성: 만들지 않는다 (근거 없는 확신 = 가짜 숫자)
- ✅ 자동 분석: 시세 데이터로 지표를 **계산**하고, 사용자 규칙 충족 여부를
  **사실로 표시**한다. 결정은 사람이 한다.

## 계산 항목 (야후 일봉 1년치 기준)

- 이동평균 5/20/120, 20일선 상승 여부(5거래일 전 대비)
- 거래량 배수(당일/20일 평균, 급증 기준 2배 — VOLUME_SPIKE 상수)
- RSI(14)
- 데이터 부족 시 None — 지어내지 않음

## 체크리스트 자동 채점

계산 결과 → trade_rules.json 항목 매핑:
ma5>ma20→c1, 20일선상승→c2, 120일선위→c3, 상승추세→c4, 거래량급증→v1
(상승추세 정의: 종가>20일선 AND 20일선 상승 — 정의는 코드에 투명하게 명시)

뉴스/재무/수급/시장/계획 항목은 자동화하지 않는다 — 판단이 필요한 영역.

## 사용

대시보드 🧭 섹션 상단 → 티커 입력 → [🔎 자동 분석]
→ 사실 패널 표시 + 차트/거래량 체크박스 자동 반영 + 합계 점수 갱신

## 테스트 (5/5, 합성 데이터)

- [x] SMA/RSI 정확성, 데이터 부족 시 None
- [x] 상승 시나리오 전항목 True + 거래량 3배 / 하락 시나리오 False
- [x] 체크리스트 id 매핑 무결성
- [ ] 야후 실호출 (사용자 환경 — 실패 시 오류 문구가 안내)

그래프가 보이면 좋겠다.
